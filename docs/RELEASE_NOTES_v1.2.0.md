## v1.2.0

### 新增
- **游戏内自动更新检测**：主菜单头部发现新版本时显示橙色「有更新 vX.X.X」徽章
- **「检查更新」入口**：点击自动查询 GitHub Releases，有新版时复制下载链接到剪贴板
- **关于页新增「更新」状态行**：显示当前版本 / 最新版本 / 是否有可用更新
- 更新检查结果缓存 1 小时，后台异步查询，不阻塞游戏

### 安装
1. 需要 Fabric Loader ≥ 0.16.9 + Minecraft 1.21.8 + Fabric API
2. 把 `mc520pro-menu-1.2.0.jar` 放进 `.minecraft/mods`
3. 游戏内按 **M** 呼出菜单
