## v1.1.0

### 新增
- **在线玩家列表页**：传送分类新增「在线玩家」入口，一次列出全部在线玩家（名字 / 延迟 / 头衔显示名），每行右侧两个按钮：
  - 「传」= 直接发送 `/tpa <玩家>`
  - 「召」= 直接发送 `/tpahere <玩家>`
  - 点击名字复制到剪贴板；自己会排在最前并高亮
- **GitHub 仓库地址**已写入关于页与 `fabric.mod.json`

### 改进
- **页签切换动画**：缓入缓出滑动 + 淡入淡出，选中光标带轻微弹性超调；卡片按顺序错峰入场，方向随切换方向变化
- **版本号自动同步**：关于页显示的版本直接从 `fabric.mod.json` 读取，不再硬编码
- **更新日志资源化**：更新日志改为 `assets/mc520pro/changelog.txt` 驱动，发版只需改一处
- 指令目录扩充至 90+ 条（含插件推断指令，标青色小点）

### 修复
- 关于页更新日志条目被截断（只显示 3 条）
- 指令清单页未连接时是空面板 → 改为居中空状态说明，无效按钮置灰
- 向导页面板留白过多、数字参数与 −/+ 按钮重叠
- 分类页签行左右留白过大且无文字 → 填满宽度并加中文标签
- 少条目分类被迫滚动 → 自动 3 列自适应

### 安装
1. 需要 Fabric Loader ≥ 0.16.9 + Minecraft 1.21.8 + Fabric API
2. 把 `mc520pro-menu-1.1.0.jar` 放进 `.minecraft/mods`
3. 游戏内按 **M** 呼出菜单
