## 1. 为什么像素统计也不能替代目视（已尝试并否决）

为避免空手交付，我用 Pillow/numpy 做了三类程序化测量：深色主色带（行/列）、亮像素行带与局部对比度"墨迹"行带、饱和色连通块（红/橙/金/绿/紫/蓝）。

结果是**这些数据不能支撑任何 A–G 结论**，理由是实测到的：

- 每张图都能测到数万级、横跨几乎整幅画面的"蓝色"饱和像素簇（世界天空/场景），说明背景没有被 UI 面板完全遮住，前景文字与背景纹理无法分离；
- 局部对比度检测在**整幅图上下都连续命中**（例如 `v8_wizard` 得到一整条 `y=3–479` 的连续墨迹带），说明统计量测到的是背景纹理而不是文字行；
- 因此我最初想用"某高度区间没有文字行"来推断"内容空洞"，在复核后被自己否掉——**这类推断不可靠，已全部丢弃，不写进结论。**

一句话：这些阈值统计既不能证明有缺陷，也不能证明没缺陷。任何基于它们的"问题清单"都会是猜测，因此本报告不提供。
